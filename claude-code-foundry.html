Microsoft × Anthropic

A multi-year agreement and partnership.

The agreement between Microsoft and Anthropic is a significant expansion of an existing technical and business partnership. Claude models now surface across the Microsoft portfolio — as APIs in Foundry, as a model choice in GitHub Copilot, and inside Microsoft 365.

Azure & Foundry
  • Claude models available as APIs via Foundry.
  • Industry-leading families: Opus, Sonnet, Haiku.
  • Deeply integrated into Foundry capabilities such as Agent Service and Model Router.
GitHub Copilot
  • Claude models are selectable directly in GitHub Copilot.
  • Includes the leading coding models: Opus 4.6, Sonnet 4.5, Haiku 4.5.
  • The same models your developers already reach for.
M365 & Copilot Studio
  • Claude models power the Researcher agent.
  • Agent Mode in Excel lets users select Claude models.
  • Agents built in Copilot Studio can select Claude models.

For both hosting options in Foundry, Anthropic remains the seller of record and the operator of the Claude models. Claude models are Non-Microsoft Products under the Product Terms, and their use is subject to the terms Anthropic provides for Claude models and APIs.

Value proposition

Why Anthropic on Foundry, rather than Anthropic alone.

It is about the platform
Foundry integration

Integrates with Foundry services including Agent Service, Model Router and Content Safety. Extend with Foundry APIs, MCP and grounding services like Bing.

Platform extensibility

Build end-to-end solutions with Azure services like Fabric and Cosmos DB. Accelerate agent development with GitHub Copilot, then expose those agents in M365, Teams and Windows — everywhere work gets done.

It is about governance & security
Identity & security

Secure access with Microsoft Entra ID, Azure RBAC and Purview. Apply the policies you already run to govern API usage and evidence compliance.

Observability & management

Monitor usage, latency and cost with Azure Monitor, API Management and Foundry — alongside every other Azure service, on one control plane.

It is about economics
Retire existing commitments

Consolidate Anthropic model spend into your Azure MACC. Apply existing Anthropic discounts and draw down on your Anthropic commits at the same time.

Token efficiency

Lower model cost through intelligent retrieval and context orchestration — fewer redundant tokens, better answer relevance, more value from every model call.

Proposed path

Prove the experience, then scale.

Step 1 · Demo

See it from the developer's seat

A live session against a Foundry endpoint: the same tooling, Entra sign-in, a real repository.

  • ~60 minutes, your engineers watching
  • Side by side with the direct setup
  • Output: a go/no-go on the experience
Step 2 · POC

One dev team, instrumented

Foundry resource, pinned deployments, RBAC, monitoring and a measured baseline.

  • 1–2 weeks, one team
  • Cost per developer and usage telemetry
  • Output: real unit economics, not a quote
Step 3 · Scale

Roll out to the wider population

Managed settings, org-wide context files, quotas and chargeback per team.

  • One-click install for your dev environment
  • Gateway policies for budget control
  • Output: governed, forecastable consumption
What we bring — and what we need

Microsoft provides the setup support at every step: resource design, RBAC, deployment pinning, gateway and cost controls. We need a named engineering sponsor and one team willing to be measured.
